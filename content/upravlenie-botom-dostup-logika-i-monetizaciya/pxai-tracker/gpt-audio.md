# Расшифровка аудио

Для расшифровки нужен ID аудиофайла в поле `file`. `gpt_audio` возвращает текст. Старое деление на «лайт» и «large» по размеру 300 КБ и фиксированная связка с текстовой моделью больше не описывают текущий сценарий.

[Открыть актуальную инструкцию](https://docs.pxsto.re/tracker/treker-zaprosy/voice/transcription-catalog).

[Общий порядок настройки трекера](https://docs.pxsto.re/tracker).
