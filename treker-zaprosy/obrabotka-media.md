# Обработка медиа

Для увеличения изображения используйте [Topaz Image Upscale](foto/topaz-image-upscale.md) с ключом `image_upscale`.

Музыкальные операции находятся в разделе [Музыка](muzyka/), работа с файлами — в разделе [Создание документов](tekstovye-modeli/sozdanie-dokumentov.md).

Отдельной действующей модели с ключом `upscale` в каталоге нет.
