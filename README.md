# PuzzleDocs

Практическая документация PuzzleAI: как выбрать модель, какие поля заполнить и где получить результат.

## Актуальный каталог

В PuzzleAI доступны текстовые, голосовые, графические, видео- и музыкальные модели. На странице каталога популярные варианты показаны сразу, а полный список текстовых моделей можно раскрыть отдельно.

Стоимость обозначается иконкой 💠: например, `💠25`. Актуальное значение показывается рядом с моделью или выбранной операцией.

[Открыть модели и стоимость](content/info/ai-modeli-i-stoimost.md)

## Быстрый старт трекера

1. В команде PuzzleBot добавьте действие **«Отправить запрос»**.
2. Укажите ссылку `https://api.pxsto.re/main/puzzlebot-tracker`.
3. Выберите метод `POST` и вид запроса `Сформированный`.
4. Передайте обязательную базу: `bot`, `token`, `user`, `model`.
5. Добавьте содержимое задачи: чаще всего `prompt`, а для медиа-моделей ещё `images` или `params`.

## Минимальный пример с комментариями

```jsonc
{
  "bot": "{{BOT_USERNAME_TEXT}}", // обязательно: username бота в PuzzleBot.
  "token": "[Ваш API-токен]", // обязательно: API-токен бота.
  "user": "{{USER_ID_TEXT}}", // обязательно: ID пользователя или сессии.
  "model": "gpt_5", // обязательно: ключ модели, которую нужно вызвать.
  "prompt": "{{prompt}}", // обычно обязательно: текст задачи; исключения описаны в статье модели.
  "send_answer": true // необязательно: отправить результат пользователю; по умолчанию `true`.
}
```

## Базовые параметры

| Параметр | Тип | Обязательный | Описание |
| --- | --- | --- | --- |
| `bot` | string | Да | Username бота. Используйте `{{BOT_USERNAME_TEXT}}`. |
| `token` | string | Да | API-токен бота. |
| `user` | string | Да | ID пользователя или сессии. Используйте `{{USER_ID_TEXT}}`. |
| `model` | string | Да | Ключ модели из нужной статьи, например `gpt_5`, `gpt_image` или `veo`. |
| `prompt` | string | Зависит от модели | Текст задачи. Для большинства моделей обязателен. |
| `images` | string | Зависит от модели | Ссылки, file_id или переменные с изображениями через запятую, без массива `[]`. |
| `params` | object | Нет | Вложенные настройки конкретной модели. |
| `role` | string | Нет | Дополнительная роль или инструкция для модели. |
| `send_answer` | boolean | Нет | `true` отправляет результат в чат, `false` сохраняет его в `{{tracker_answer}}`. |
| `chat` | string/number | Для ответа в группу | Числовой Telegram ID группы или форума, например `-1001234567890`. Без этого поля ответ отправляется пользователю из `user`. |
| `topic` | number | Для ответа в топик | ID нужного топика Telegram-форума. Передавайте вместе с `chat`; для обычной группы поле не нужно. |

## Ответы в группы и топики Telegram

Трекер поддерживает отправку результата в группу и в отдельный топик форума. Поля `chat` и `topic` добавляются на верхнем уровне запроса, рядом с `user` и `model`, а не внутри `params`.

* **Личный чат:** оставьте `user`, не добавляйте `chat` и `topic`.
* **Обычная группа:** добавьте `chat` с числовым ID группы; `topic` не передавайте.
* **Топик форума:** добавьте `chat` с ID группы-форума и `topic` с ID нужного топика.

`user` — ID пользователя, который запускает запрос. Не заменяйте его ID группы: адрес доставки задаётся отдельно в `chat`.

### Пример ответа в топик

```jsonc
{
  "bot": "{{BOT_USERNAME_TEXT}}", // username подключённого бота.
  "token": "[Ваш API-токен]", // API-токен из настроек интеграции.
  "user": "{{USER_ID_TEXT}}", // ID пользователя, запускающего запрос.
  "model": "gpt_5", // ключ доступной модели.
  "prompt": "{{prompt}}", // вопрос пользователя.
  "send_answer": true, // отправить готовый ответ в Telegram.
  "chat": "-1001234567890", // пример: замените на ID своей группы-форума.
  "topic": 123 // пример: замените на ID нужного топика.
}
```

Для ответа в обычную группу используйте тот же запрос без строки `topic`. В действии PuzzleBot «Отправить запрос» с видом `Сформированный` добавьте эти же ключи и значения отдельными параметрами.

### Как узнать ID группы и топика

Точные значения есть во входящем Telegram-сообщении: `message.chat.id` — ID группы, `message.message_thread_id` — ID топика. Если адрес должен меняться вместе с местом запуска команды, сохраните эти значения в переменные сценария и подставляйте их в `chat` и `topic`. Трекер сам не определяет топик по тексту вопроса.

ID можно узнать и из ссылки на сообщение в нужном топике. Например, для `https://t.me/c/1234567890/123/456` передайте `chat: "-1001234567890"` и `topic: 123`; последнее число `456` — ID сообщения. Если ссылка содержит `?thread=123`, ID топика — значение `thread`. В публичной ссылке вида `https://t.me/имя_группы/123/456` топик также `123`, но числовой ID группы нужно получить отдельно. Форматы ссылок описаны в [документации Telegram](https://core.telegram.org/api/links#message-links).

Для обычной группы `message_thread_id` отсутствует. Номер отдельного сообщения (`message_id`) не заменяет ID топика. Для топика «Общее» можно не передавать `topic`; не копируйте в него ID случайного сообщения.

### Что настроить перед запросом

1. Добавьте бота в целевую группу и разрешите ему отправлять сообщения. Для медиа-ответов нужны права на соответствующий вид медиа.
2. Если команду запускают из группы, подключите группу к боту в разделе PuzzleBot «Ресурсы» и настройте запуск команды в этом ресурсе.
3. Проверьте, что выбранная модель включена для бота и запрос не заблокирован тарифом, балансом или лимитами.
4. Для форума выберите существующий доступный топик. Закрытый или удалённый топик может не принять ответ.

Если команда должна запускаться от обычного сообщения в группе, учитывайте режим приватности Telegram: при включённом режиме бот получает адресованные ему команды и ответы на свои сообщения. Проверьте запуск через `/команда@имя_бота` или ответом на сообщение бота. Подробнее — в [официальной справке Telegram](https://core.telegram.org/bots/faq#what-messages-will-my-bot-get).

### Если ответа нет или он пришёл не туда

* **Ответ пришёл в личку:** проверьте, что `chat` заполнен числовым ID группы и передан на верхнем уровне запроса.
* **Ответ пришёл в «Общее», а нужен другой топик:** передайте `topic` вместе с `chat`; используйте ID топика, а не отдельного сообщения.
* **Ответ сохранён, но сообщения нет:** при `send_answer: false` результат сохраняется в `{{tracker_answer}}`, отправки в группу или топик нет. Для отправки задайте `true`.
* **Команда не запустилась:** проверьте подключение ресурса в PuzzleBot, правила запуска и режим приватности Telegram.
* **Запрос принят, но ответа нет:** проверьте итог обработки и ошибку доставки. Успешный HTTP-ответ трекера означает приём запроса, а не гарантирует готовый ответ в Telegram.

## Puzzle AI Tracker

Puzzle AI Tracker позволяет владельцам Puzzle AI плагина собирать собственные сценарии в PuzzleBot: текстовые ответы, генерацию изображений, видео, аудио, документов и медиа-обработку.

Главное правило: сначала передайте обязательную базу, затем добавляйте только параметры выбранной модели. Необязательные поля не нужно создавать в запросе, пока они реально не используются.
