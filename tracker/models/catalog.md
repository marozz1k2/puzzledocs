# Каталог моделей

В PuzzleAI доступны модели для текста, изображений, видео, голоса и музыки. Полный пользовательский список со стоимостью находится на странице [Модели и стоимость](https://docs.pxsto.re/info/ai-modeli-i-stoimost).

## Что доступно

| Категория | Раздел |
| --- | --- |
| Текст | [Текстовые модели](text/README.md) |
| Изображения | [Фото-модели](photo/README.md) |
| Видео | [Видео-модели](video/README.md) |
| Голос | [Голосовые модели](voice/README.md) |
| Музыка | [Музыкальные модели](music/README.md) |

Стоимость указывается в формате `💠25`. Перед запуском ориентируйтесь на значение рядом с выбранной моделью или операцией.

## Как выбрать модель в Трекере

1. Откройте нужную категорию в каталоге.
2. Выберите модель и скопируйте её ключ в поле `model`.
3. Добавьте только те параметры, которые нужны выбранной операции.
4. Проверьте стоимость и запустите задачу.

Для обычного запроса достаточно `bot`, `token`, `user`, `model` и `prompt`. Модели для изображений, видео, голоса и музыки могут попросить исходный файл, ID предыдущей задачи или дополнительные настройки.
