# GPT Image 2.5

Создаёт изображение по тексту и позволяет использовать изображения-референсы. Ключ трекера — `gpt_image`; текущая модель — GPT Image 2.5.

## Как отправить запрос

URL-адрес: `https://api.pxsto.re/main/puzzlebot-tracker`. Метод `POST`, вид запроса PuzzleBot **«Сформированный»**.

## Пример запроса с комментариями

```jsonc
{
  "bot": "{{BOT_USERNAME_TEXT}}", // обязательно: username бота.
  "token": "[Ваш API-токен]", // обязательно: токен интеграции.
  "user": "{{USER_ID_TEXT}}", // обязательно: ID пользователя.
  "model": "gpt_image", // обязательно: действующий ключ модели.
  "prompt": "Обложка книги: горное озеро на рассвете", // обязательно: описание результата.
  "params": { // необязательно: параметры изображения.
    "resolution": "1K", // необязательно: разрешение из настроек текущей модели.
    "aspect_ratio": "1:1" // необязательно: формат кадра.
  },
  "send_answer": true // необязательно: отправить результат в чат.
}
```

## Параметры

| Параметр | Обязательный | Описание |
| --- | --- | --- |
| `bot`, `token`, `user` | Да | Username, токен интеграции и ID пользователя. |
| `model` | Да | `gpt_image`. |
| `prompt` | Да | Что создать или изменить. |
| `images` | Для работы по референсу | Ссылки или ID изображений через запятую. |
| `params.resolution` | Нет | `1K`, `2K`, `4K`; по умолчанию `1K`. |
| `params.aspect_ratio` | Нет | `1:1`, `3:2`, `2:3`, `16:9`; по умолчанию `1:1`. |
| `send_answer` | Нет | Включить или отключить отправку результата в чат. |

Для новых запросов используйте параметры текущей модели. Прежние настройки субмоделей GPT Image 1.5/2 и размеров в пикселях не являются настройками каталога GPT Image 2.5.

## Ответ

Запрос выполняется асинхронно: HTTP-ответ подтверждает приём, а готовый результат приходит после обработки.

При `send_answer=true` результат отправляется в чат. При `send_answer=false` отправка отключена. Для продолжения сценария используйте `{{tracker_answer}}` после завершения задачи; сохранение переменной должно быть включено в настройках бота. Медиа сохраняется ссылкой или `file_id` в зависимости от настройки.
