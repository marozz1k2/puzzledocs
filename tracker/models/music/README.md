# Музыкальные модели

В PuzzleAI можно создавать песни, редактировать готовые треки, разделять дорожки, делать каверы и экспортировать результат. Сначала выберите модель, затем операцию — набор полей и стоимость изменятся автоматически.

## Какую модель выбрать

| Модель | Ключ `model` | Лучше всего подходит для |
| --- | --- | --- |
| [Suno](suno.md) | `suno` | Песни, каверы, ремастеринг, stems, MIDI и работа с фрагментами. |
| [Producer](producer.md) | `producer` | Генерация и точечная замена музыки или вокала. |
| [QW Music](qw-music.md) | `qwmusic` | Песня по описанию, своему тексту, стилю или мелодии-референсу. |
| [FlowMusic](flow-music.md) | `flowmusic` | Генерация, продление, замена фрагмента и экспорт. |

## Как отправить запрос

- URL-адрес: `https://api.pxsto.re/main/puzzlebot-tracker`
- Метод: `POST`
- Вид запроса в PuzzleBot: `Сформированный`

У всех музыкальных моделей одна основа: `bot`, `token`, `user`, `model`. Операция передаётся в поле `action`.

```jsonc
{
  "bot": "{{BOT_USERNAME_TEXT}}", // обязательно: username бота.
  "token": "[Ваш API-токен]", // обязательно: API-токен бота.
  "user": "{{USER_ID_TEXT}}", // обязательно: ID пользователя.
  "model": "suno", // обязательно: ключ музыкальной модели.
  "action": "generate", // обязательно: выбранная операция.
  "prompt": "{{music_prompt}}", // для генерации: описание или текст песни.
  "send_answer": true // необязательно: отправить результат в чат.
}
```

## Стоимость

Операция `generate` в Suno, Producer, QW Music и FlowMusic стоит `💠30`. У остальных операций своя стоимость — точные значения указаны на странице каждой модели и показываются перед запуском.

## Результат

В зависимости от операции ответ может содержать готовый трек, второй вариант, отдельные дорожки, видео, текст с таймкодами, WAV, MIDI или BPM. Если `send_answer=false`, результат сохранится в `{{tracker_answer}}`.

ID готового трека записывается в переменную PuzzleBot: её имя передаётся в `music_id_variable`. Треки в MP3 и M4A приходят аудиоплеером, WAV и остальные форматы — файлом-вложением; если мессенджер не забрал файл, в чат придёт ссылка на скачивание. Подробности для Suno — в статье [Suno](suno.md).
