# suno: свой текст и стиль

Кастомный режим подходит, когда нужно отдельно передать текст песни, стиль и название. Стоимость — `💠30`.

```jsonc
{
  "bot": "{{BOT_USERNAME_TEXT}}", // обязательно.
  "token": "[Ваш API-токен]", // обязательно.
  "user": "{{USER_ID_TEXT}}", // обязательно.
  "model": "suno", // обязательно.
  "action": "generate", // создать песню.
  "mv": "chirp-v5-5", // версия Suno.
  "prompt": "{{suno_prompt}}", // описание песни или инструкция.
  "lyrics": "{{suno_lyrics}}", // отдельная переменная со своим текстом песни.
  "custom": true, // включить кастомный режим.
  "title": "{{song_title}}", // название.
  "tags": "indie pop, warm vocal, summer", // стиль и настроение.
  "negative_tags": "noise, clipping", // что исключить.
  "vocal_gender": "female", // необязательно: пол вокала.
  "instrumental": false // true для трека без вокала.
}
```

`prompt` и `lyrics` — разные параметры. В `prompt` передавайте замысел и ожидаемое звучание, в `lyrics` — только слова песни с разметкой `[verse]`, `[chorus]` и т. п. Старые сценарии, где слова передавались только в `prompt`, продолжат работать, но для новых сценариев используйте раздельные переменные.

Не добавляйте пустые поля: для инструментала достаточно описания, стиля и `instrumental=true`.

## Инструментал в кастомном режиме

При `custom: true` и `instrumental: true` текст песни не нужен. Описание из `prompt` уходит в стиль, поэтому оно не превращается в слова:

```jsonc
{
  "model": "suno",
  "action": "generate",
  "custom": true,
  "instrumental": true, // трек без вокала.
  "prompt": "Напряжённый эпичный трек для трейлера", // станет частью стиля.
  "tags": "epic, trailer, drums"
}
```

## Пол вокала и вариативность

`vocal_gender` принимает `male` и `female` (а также `мужской` и `женский`); в кастомном режиме пол дополнительно закрепляется стилевым тегом. Точность стиля, близость к исходному аудио и степень экспериментов настраиваются полями `style_weight`, `audio_weight` и `weirdness_constraint` — подробности в разделе «Тонкая настройка звучания» статьи [suno](suno.md).
