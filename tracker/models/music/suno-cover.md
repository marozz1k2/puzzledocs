# suno: кавер

Операция `cover` переносит готовый трек в другое звучание. Стоимость — `💠30`.

```jsonc
{
  "bot": "{{BOT_USERNAME_TEXT}}", // обязательно.
  "token": "[Ваш API-токен]", // обязательно.
  "user": "{{USER_ID_TEXT}}", // обязательно.
  "model": "suno", // обязательно.
  "action": "cover", // создать кавер.
  "music_id": "{{suno_music_id}}", // ID исходного трека из music_id_variable.
  "mv": "chirp-v5-5", // версия Suno.
  "prompt": "Акустический кавер с мягким женским вокалом", // новое звучание.
  "title": "{{song_title}}" // необязательно: название.
}
```

## Откуда взять исходный трек

Подойдёт любой из трёх вариантов:

- `music_id` — ID трека из предыдущей операции;
- `audio_url` — прямая публичная ссылка на аудио;
- `file_id` — файл из стандартной **Формы ввода** PuzzleBot.

Отдельная загрузка (`action: upload`, `💠3`) нужна только тогда, когда один и тот же трек используется в нескольких операциях подряд.

## Кавер со своим текстом

При `custom: true` текст песни передавайте в `lyrics`, а описание нового звучания — в `prompt`. Если `lyrics` не заполнен, запрос не уйдёт в обработку и вернётся подсказка:

> Для ремикса с текстом заполните поле lyrics или отключите custom. Для инструментального ремикса установите instrumental=true.

Так описание ремикса больше не попадает в Suno как текст песни.

Для инструментального кавера `lyrics` не нужен:

```jsonc
{
  "model": "suno",
  "action": "cover",
  "audio_url": "{{track_url}}", // исходное аудио без отдельной загрузки.
  "custom": true,
  "instrumental": true, // кавер без вокала, текст не требуется.
  "prompt": "Лоу-фай версия без вокала", // уйдёт в стиль.
  "tags": "lo-fi, tape saturation"
}
```
