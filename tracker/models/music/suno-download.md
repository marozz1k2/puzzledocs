# suno: скачивание готового трека

Операция `download` скачивает ранее созданный трек в MP3, M4A или WAV. Она не создаёт новую музыку и не меняет вокал, стиль или длительность. Стоимость одного запроса — `💠1`.

## Как отправлять запрос

- Ссылка: `https://api.pxsto.re/main/puzzlebot-tracker`
- Метод: `POST`
- Вид запроса в PuzzleBot: `Сформированный`
- Формат тела: `application/json` или те же поля в параметрах запроса.

Сначала сохраните ID готового трека в переменную, например `suno_music_id`. Затем передайте этот ID в `music_id` и выберите один формат в поле `format`.

## Пример запроса с комментариями

```jsonc
{
  "bot": "{{BOT_USERNAME_TEXT}}", // обязательно: username бота в PuzzleBot.
  "token": "[Ваш API-токен]", // обязательно: API-токен бота.
  "user": "{{USER_ID_TEXT}}", // обязательно: ID пользователя или сессии.
  "model": "suno", // обязательно: музыкальная модель.
  "action": "download", // обязательно: скачать готовый трек.
  "music_id": "{{suno_music_id}}", // обязательно: ID ранее созданного или загруженного трека.
  "format": "mp3", // необязательно: mp3, m4a или wav; по умолчанию mp3.
  "send_answer": true // необязательно: отправить файл пользователю.
}
```

## Параметры

| Параметр | Тип | Обязательный | Описание |
| --- | --- | --- | --- |
| `bot` | string | Да | Username бота: `{{BOT_USERNAME_TEXT}}`. |
| `token` | string | Да | API-токен бота. |
| `user` | string | Да | ID пользователя: `{{USER_ID_TEXT}}`. |
| `model` | string | Да | Укажите `suno`. |
| `action` | string | Да | Укажите `download`. |
| `music_id` | string | Да | ID готового трека. Обычно берётся из переменной, указанной при создании или загрузке музыки. |
| `format` | string | Нет | Формат файла: `mp3`, `m4a` или `wav`. Если поле не передано, используется `mp3`. |
| `send_answer` | boolean | Нет | `true` — отправить результат пользователю; `false` — сохранить результат без сообщения в чат. |

Поля генерации, включая `prompt`, `custom`, `instrumental`, `lyrics` и `tags`, для скачивания не нужны и на готовый файл не влияют.

## Как настроить в Трекере

1. Выберите музыкальную модель `suno`.
2. В поле операции выберите **«Скачать аудио»** (`download`).
3. В `music_id` подставьте переменную с ID готового трека.
4. В поле **«Формат файла»** выберите MP3, M4A или WAV.
5. Включите отправку ответа, если файл должен прийти пользователю в чат.

Для одного запуска выбирается один формат. Чтобы получить тот же трек в другом формате, отправьте ещё один запрос с тем же `music_id` и новым значением `format`. Каждый успешный запрос оплачивается отдельно.

## Ответ

Результат содержит ссылку на готовый файл выбранного формата. MP3 и M4A обычно приходят в чат как аудио, WAV — как файл-вложение. Если мессенджер не сможет принять файл, пользователь получит ссылку для скачивания.

## Важно

- Используйте ID самого трека, а не ID запроса и не ссылку на аудио.
- Повторный запрос для того же `music_id` считается новой операцией и снова стоит `💠1`.
- Для старых сценариев `action: wav` продолжает работать и всегда возвращает WAV. Для новых сценариев удобнее использовать `action: download` и явно указывать `format`.
