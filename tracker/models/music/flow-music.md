# flowmusic

`flowmusic` создаёт и обрабатывает музыку. После выбора операции добавляйте только относящиеся к ней поля.

## Пример генерации

```jsonc
{
  "bot": "{{BOT_USERNAME_TEXT}}", // обязательно: username бота.
  "token": "[Ваш API-токен]", // обязательно: API-токен бота.
  "user": "{{USER_ID_TEXT}}", // обязательно: ID пользователя.
  "model": "flowmusic", // обязательно: ключ FlowMusic.
  "action": "generate", // обязательно: создать музыку.
  "sound_prompt": "Спокойный эмбиент с фортепиано", // описание звучания.
  "lyrics": "{{lyrics}}", // необязательно: текст песни.
  "send_answer": true // необязательно: отправить результат в чат.
}
```

## Операции и стоимость

| Операция | `action` | Основные параметры | Стоимость |
| --- | --- | --- | ---: |
| Создать музыку | `generate` | `sound_prompt`, `lyrics` | 💠3 |
| Продолжить трек | `extend` | `clip_id`, позиция продолжения | 💠3 |
| Заменить фрагмент | `replace` | `clip_id`, начало, конец, инструкция | 💠3 |
| Разделить дорожки | `stems` | `clip_id` | 💠3 |
| Создать текст песни | `lyrics` | `prompt` | 💠1 |
| Скачать аудио | `download_audio` | `clip_id`, `format` | 💠1 |
| Создать видео | `video_clip` | `clip_id`, `preset` | 💠1 |
| Загрузить аудио | `upload_audio` | `audio_url` | 💠1 |

## Основные параметры

| Ключ | Значение | Описание |
| --- | --- | --- |
| `model` | `flowmusic` | Модель FlowMusic. |
| `action` | значение из таблицы | Выбранная операция. |
| `sound_prompt` | текст | Описание звучания. |
| `lyrics` | текст | Текст песни. |
| `clip_id` | ID трека | Исходный трек для обработки. |
| `audio_url` | URL файла | Аудио для загрузки. |
| `format` | `mp3` или `wav` | Формат скачивания. |
| `preset` | текст | Оформление видео. |

## Ответ

Готовый ответ содержит ссылку на результат и ID трека. Если `send_answer=false`, он сохранится в `{{tracker_answer}}`.
