# Версии Suno

Версия передаётся в поле `mv`. Если поле не добавлено, используется версия по умолчанию.

| Значение `mv` | Когда выбирать |
| --- | --- |
| `chirp-v5-5` | Новая версия по умолчанию. |
| `chirp-v5` | Поколение Suno 5. |
| `chirp-v4-5+` | Расширенная версия 4.5. |
| `chirp-v4-5` | Стабильная версия 4.5. |
| `chirp-v4-5-all` | Вариант 4.5 для поддерживаемых операций. |
| `chirp-v4` | Совместимость со старыми сценариями. |
| `chirp-v3-5` | Совместимость со старыми сценариями. |
| `chirp-v3-0` | Самая ранняя доступная версия. |

Для новых сценариев начинайте с `chirp-v5-5`. Если выбранная операция не поддерживает версию, используйте вариант, который показывает интерфейс.
