# Модели Suno

Модель передаётся в поле `mv`. Если поле не добавлено, используется `chirp-v6`.

| Значение `mv` | Когда выбирать |
| --- | --- |
| `chirp-v6` | Основная модель по умолчанию: наиболее точный и отполированный результат. |
| `chirp-v6-wild` | Более смелые и разнообразные интерпретации, когда важен эксперимент. |
| `chirp-v6-mini` | Быстрые черновики и более экономичная генерация. |

Модели серий 3–5 удалены. Старые сохранённые значения автоматически перенаправляются на `chirp-v6`, но в новых сценариях указывайте только одну из трёх актуальных моделей.

Подробнее: [описание Suno v6](https://suno.com/blog/introducing-v6).
