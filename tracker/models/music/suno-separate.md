# suno: разделение дорожек

Suno умеет отделить выбранную дорожку или подготовить полный набор stems.

## Вокал и инструментал — `💠60`

```jsonc
{
  "bot": "{{BOT_USERNAME_TEXT}}", // обязательно.
  "token": "[Ваш API-токен]", // обязательно.
  "user": "{{USER_ID_TEXT}}", // обязательно.
  "model": "suno", // обязательно.
  "action": "stems", // разделить вокал и инструментал.
  "music_id": "{{music_id}}", // ID исходного трека.
  "stem_type": "vocals" // нужная дорожка.
}
```

## Все дорожки — `💠120`

Для полного набора используйте `action=stems_all` и передайте `music_id`.
