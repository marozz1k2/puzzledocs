# suno: разделение дорожек

Suno умеет отделить выбранную дорожку или подготовить полный набор stems.

## Вокал и инструментал — `💠60`

```jsonc
{
  "bot": "{{BOT_USERNAME_TEXT}}", // обязательно.
  "token": "[Ваш API-токен]", // обязательно.
  "user": "{{USER_ID_TEXT}}", // обязательно.
  "model": "suno", // обязательно.
  "action": "stems", // разделить вокал и инструментал.
  "music_id": "{{suno_music_id}}", // ID исходного трека из music_id_variable.
  "stem_type": "vocals" // нужная дорожка.
}
```

## Все дорожки — `💠120`

Для полного набора используйте `action=stems_all` и передайте `music_id`.

## Добавить дорожку — `💠30`

`add_stem` и `add_instrumental` дописывают новую дорожку к готовому треку. Флаг `instrumental` эти операции не поддерживают — передавайте только `music_id` и описание:

```jsonc
{
  "model": "suno",
  "action": "add_stem",
  "music_id": "{{suno_music_id}}", // ID исходного трека.
  "prompt": "Добавь партию бас-гитары" // что дописать.
}
```

Если трек сначала загружается через `action: upload`, второй запрос можно отправлять сразу: загрузка не занимает слот медленного режима.

## Как приходит результат

Дорожки и экспорт в WAV приходят файлом-вложением, а не аудиоплеером: плеер такие форматы не принимает. Если мессенджер не забрал файл, в чат придёт ссылка на скачивание.
