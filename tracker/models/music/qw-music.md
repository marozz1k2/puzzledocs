# qwmusic

`qwmusic` создаёт песню по обычному описанию, своему тексту и стилю или мелодии-референсу. Стоимость генерации — `💠1`.

## Пример генерации

```jsonc
{
  "bot": "{{BOT_USERNAME_TEXT}}", // обязательно: username бота.
  "token": "[Ваш API-токен]", // обязательно: API-токен бота.
  "user": "{{USER_ID_TEXT}}", // обязательно: ID пользователя.
  "model": "qwmusic", // обязательно: ключ QW Music.
  "action": "generate", // обязательно: создать музыку.
  "prompt": "Лёгкая поп-песня о летнем путешествии", // описание музыки.
  "format": "mp3", // необязательно: wav, mp3 или flac.
  "send_answer": true // необязательно: отправить результат в чат.
}
```

## Свой текст и стиль

Включите `custom_mode=true`, затем передайте `lyrics` и `style`.

```jsonc
{
  "bot": "{{BOT_USERNAME_TEXT}}", // обязательно.
  "token": "[Ваш API-токен]", // обязательно.
  "user": "{{USER_ID_TEXT}}", // обязательно.
  "model": "qwmusic", // обязательно.
  "action": "generate", // обязательно.
  "custom_mode": true, // использовать свой текст и стиль.
  "lyrics": "{{lyrics}}", // текст песни.
  "style": "dream pop, female vocal, warm synths", // описание стиля.
  "audio_urls": "{{melody_url}}", // необязательно: мелодия-референс.
  "return_candidate_audio": true, // необязательно: вернуть второй вариант.
  "format": "mp3" // необязательно: формат результата.
}
```

## Параметры

| Ключ | Значение | Описание |
| --- | --- | --- |
| `model` | `qwmusic` | Модель QW Music. |
| `action` | `generate` | Создать музыку. |
| `prompt` | текст | Описание музыки для обычного режима. |
| `custom_mode` | `true` / `false` | Использовать отдельные поля текста и стиля. |
| `lyrics` | текст | Свой текст песни. Нужен при `custom_mode=true`. |
| `style` | текст | Жанр, настроение и характер звучания. |
| `audio_urls` | URL или переменная | Мелодия-референс. |
| `return_candidate_audio` | `true` / `false` | Вернуть второй вариант трека. |
| `return_post_info` | `true` / `false` | Вернуть уточнённые стиль и текст. |
| `format` | `wav`, `mp3` или `flac` | Формат результата. |
| `sample_rate` | число | Частота дискретизации; по умолчанию 48000. |

## Ответ

Ответ может содержать основной трек, второй вариант и уточнённые текст со стилем. Если `send_answer=false`, результат сохранится в `{{tracker_answer}}`.
