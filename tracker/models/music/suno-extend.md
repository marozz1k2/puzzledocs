# suno: продление трека

Операция `extend` продолжает существующую песню. Стоимость — `💠30`.

```jsonc
{
  "bot": "{{BOT_USERNAME_TEXT}}", // обязательно.
  "token": "[Ваш API-токен]", // обязательно.
  "user": "{{USER_ID_TEXT}}", // обязательно.
  "model": "suno", // обязательно.
  "action": "extend", // продолжить трек.
  "music_id": "{{suno_music_id}}", // ID исходного трека из music_id_variable.
  "continue_at": 60, // необязательно: с какой секунды продолжить.
  "mv": "chirp-v5-5", // версия Suno.
  "prompt": "Добавь финальный припев и плавное завершение", // инструкция.
  "instrumental": false // true, чтобы продолжение осталось без вокала.
}
```

Используйте ID из результата генерации или загрузки аудио.

## Что можно не передавать

- `continue_at` необязателен. Если поле не передано, трекер сам определит длительность исходного трека и продолжит с его конца.
- Отдельная загрузка (`action: upload`) не обязательна: вместо `music_id` можно передать `audio_url` с публичной ссылкой или `file_id` из формы ввода PuzzleBot.

## Инструментальное продолжение

`instrumental: true` теперь доходит до Suno и в продлении: продолжение инструментального трека больше не приходит с вокалом. Поле читается без учёта регистра, поэтому `Instrumental` из настроек PuzzleBot тоже сработает.

## Продление со своим текстом

В кастомном режиме поля не конфликтуют:

```jsonc
{
  "model": "suno",
  "action": "extend",
  "music_id": "{{suno_music_id}}",
  "custom": true, // свой текст и стиль.
  "lyrics": "{{suno_lyrics}}", // слова для продолжения.
  "prompt": "Оркестровая аранжировка, живые струнные", // описание звучания.
  "tags": "cinematic, orchestral",
  "vocal_gender": "female" // пол вокала.
}
```

Описание из `prompt` не теряется: трекер добавляет его к стилю, потому что поле текста песни занято значением `lyrics`. Пол вокала дополнительно закрепляется стилевым тегом.
