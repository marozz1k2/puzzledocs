# suno

`suno` создаёт песни и инструменталы, редактирует готовые треки и экспортирует результат в разные форматы. Операция выбирается через `action`.

## Пример генерации

```jsonc
{
  "bot": "{{BOT_USERNAME_TEXT}}", // обязательно: username бота.
  "token": "[Ваш API-токен]", // обязательно: API-токен бота.
  "user": "{{USER_ID_TEXT}}", // обязательно: ID пользователя.
  "model": "suno", // обязательно: ключ Suno.
  "action": "generate", // обязательно: создать песню.
  "mv": "chirp-v5-5", // необязательно: версия Suno.
  "prompt": "{{suno_prompt}}", // обязательно: идея или текст песни.
  "custom": false, // необязательно: true для своего текста и стиля.
  "instrumental": false, // необязательно: true для трека без вокала.
  "send_answer": true // необязательно: отправить результат в чат.
}
```

| Операция | `action` | Что понадобится | Стоимость |
| --- | --- | --- | ---: |
| Создать песню | `generate` | описание или текст песни | 💠30 |
| Продолжить песню | `extend` | ID трека, позиция продолжения | 💠30 |
| Сделать кавер | `cover` | ID трека, новое описание | 💠30 |
| Разделить вокал и инструментал | `stems` | ID трека, тип дорожки | 💠30 |
| Разделить все дорожки | `stems_all` | ID трека | 💠30 |
| Добавить вокал | `add_vocals` | ID трека, описание | 💠30 |
| Добавить инструментал | `add_instrumental` | ID трека, описание | 💠30 |
| Добавить дорожку | `add_stem` | ID трека, описание | 💠30 |
| Сделать ремастеринг | `remaster` | ID трека | 💠30 |
| Заменить фрагмент | `replace_section` | ID трека, начало, конец, новый текст | 💠30 |
| Создать мэшап | `mashup` | ID нескольких треков | 💠30 |
| Создать по референсам | `inspo` | 1–4 URL аудио, описание | 💠30 |
| Развить сэмпл | `sample` | ID или аудио, границы сэмпла | 💠30 |
| Создать звук | `sounds` | описание звука | 💠30 |
| Обрезать трек | `crop` | ID трека, начало и конец | 💠30 |
| Удалить фрагмент | `remove_section` | ID трека, начало и конец | 💠30 |
| Добавить плавное появление | `fade_in` | ID трека, длительность эффекта | 💠30 |
| Добавить плавное затухание | `fade_out` | ID трека, длительность эффекта | 💠30 |
| Изменить скорость | `adjust_speed` | ID трека, множитель скорости | 💠30 |
| Склеить части | `concat` | ID трека | 💠30 |
| Получить текст с таймкодами | `aligned_lyrics` | ID трека | 💠30 |
| Создать видео | `generate_video` | ID трека | 💠30 |
| Экспортировать WAV | `wav` | ID трека | 💠30 |
| Создать персону | `persona` | ID трека, имя, описание | 💠30 |
| Извлечь вокал | `vox` | ID трека, границы вокала | 💠30 |
| Улучшить теги | `upsample_tags` | музыкальные теги | 💠30 |
| Экспортировать MIDI | `gen_midi` | ID трека | 💠30 |
| Определить BPM | `gen_bpm` | ID трека | 💠30 |
| Создать текст песни | `lyrics` | описание текста | 💠30 |
| Загрузить аудио | `upload` | URL аудио | 💠30 |
| Создать голос | `create_voice` | URL аудио | 💠30 |

## Основные параметры

| Ключ | Значение | Описание |
| --- | --- | --- |
| `model` | `suno` | Модель Suno. |
| `action` | значение из таблицы | Выбранная операция. |
| `mv` | например `chirp-v5-5` | Версия Suno. |
| `prompt` | текст или переменная | Идея, текст песни или инструкция. |
| `music_id` | ID готового трека | Нужен для большинства операций редактирования. |
| `custom` | `true` / `false` | Использовать свой текст и стиль. |
| `instrumental` | `true` / `false` | Создать трек без вокала. |
| `title` | текст | Название результата. |
| `tags` | стили через запятую | Жанр, настроение и звучание. |
| `audio_url` | URL файла | Исходное или референс-аудио. |

Поля, которые не относятся к выбранной операции, добавлять не нужно.

## Ответ

Задача выполняется в фоне. Готовый ответ содержит ссылку на аудио и ID трека для следующих операций. Если `send_answer=false`, результат сохранится в `{{tracker_answer}}`.
