# suno

`suno` создаёт песни и инструменталы, редактирует готовые треки и экспортирует результат в разные форматы. Операция выбирается через `action`.

## Пример генерации

```jsonc
{
  "bot": "{{BOT_USERNAME_TEXT}}", // обязательно: username бота.
  "token": "[Ваш API-токен]", // обязательно: API-токен бота.
  "user": "{{USER_ID_TEXT}}", // обязательно: ID пользователя.
  "model": "suno", // обязательно: ключ Suno.
  "action": "generate", // обязательно: создать песню.
  "mv": "chirp-v5-5", // необязательно: версия Suno.
  "prompt": "{{suno_prompt}}", // обязательно: идея, стиль или инструкция; не текст песни.
  "custom": false, // необязательно: true для своего текста и стиля.
  "instrumental": false, // необязательно: true для трека без вокала.
  "send_answer": true // необязательно: отправить результат в чат.
}
```

Для режима `custom=true` используйте две разные переменные: `prompt` — описание результата, а `lyrics` — готовый текст песни. Не подставляйте одну и ту же переменную в оба поля.

```jsonc
{
  "model": "suno",
  "action": "generate",
  "prompt": "{{suno_prompt}}", // описание песни или инструкция.
  "lyrics": "{{suno_lyrics}}", // отдельная переменная с текстом песни.
  "custom": true,
  "tags": "indie pop, warm vocal"
}
```

## Загрузка трека и переменная Music ID

1. В PuzzleBot откройте раздел **Переменные** и создайте персональную текстовую переменную, например `suno_music_id`.
2. В сценарии попросите пользователя отправить аудиофайл. Получите прямую ссылку на этот файл и подставьте её в `audio_url`.
3. Передайте имя созданной переменной в `music_id_variable`. После успешной загрузки трекер запишет в неё значение `data.music_id`, полученное от Suno.

```jsonc
{
  "bot": "{{BOT_USERNAME_TEXT}}",
  "token": "[Ваш API-токен]",
  "user": "{{USER_ID_TEXT}}",
  "model": "suno",
  "action": "upload",
  "audio_url": "{{suno_audio_url}}", // прямая публичная ссылка на загруженный пользователем трек.
  "music_id_variable": "suno_music_id", // имя переменной без фигурных скобок.
  "send_answer": false
}
```

После завершения используйте `"music_id": "{{suno_music_id}}"` в `extend`, `cover`, `stems` и других операциях. Переменную нужно создать заранее: трекер не создаёт её автоматически. Если `send_answer=false`, сообщение с результатом в чат не отправляется, но `music_id_variable` заполняется.

| Сделать кавер | `cover` | ID трека, новое описание | 💠30 |
| Разделить вокал и инструментал | `stems` | ID трека, тип дорожки | 💠60 |
| Разделить все дорожки | `stems_all` | ID трека | 💠120 |
| Добавить вокал | `add_vocals` | ID трека, описание | 💠30 |
| Добавить инструментал | `add_instrumental` | ID трека, описание | 💠30 |
| Добавить дорожку | `add_stem` | ID трека, описание | 💠30 |
| Сделать ремастеринг | `remaster` | ID трека | 💠30 |
| Заменить фрагмент | `replace_section` | ID трека, начало, конец, новый текст | 💠30 |
| Создать мэшап | `mashup` | ID нескольких треков | 💠30 |
| Создать по референсам | `inspo` | 1–4 URL аудио, описание | 💠40 |

| Извлечь вокал | `vox` | ID трека, границы вокала | 💠0 |

| Экспортировать MIDI | `gen_midi` | ID трека | 💠30 |
| Определить BPM | `gen_bpm` | ID трека | 💠0 |
| Создать текст песни | `lyrics` | описание текста | 💠5 |
| Загрузить аудио | `upload` | URL аудио | 💠3 |
| Создать голос | `create_voice` | URL аудио | 💠10 |

## Основные параметры

| Ключ | Значение | Описание |
| --- | --- | --- |
| `model` | `suno` | Модель Suno. |
| `action` | значение из таблицы | Выбранная операция. |
| `mv` | например `chirp-v5-5` | Версия Suno. |
| `prompt` | текст или переменная | Идея, стиль или инструкция для результата. |
| `lyrics` | текст или переменная | Отдельный готовый текст песни для `custom=true`. |
| `music_id` | ID готового трека | Нужен для большинства операций редактирования. |
| `music_id_variable` | имя переменной PuzzleBot | Куда записать ID, возвращённый операцией `upload`. Переменная должна существовать заранее. |
| `custom` | `true` / `false` | Использовать свой текст и стиль. |
| `instrumental` | `true` / `false` | Создать трек без вокала. |
| `title` | текст | Название результата. |
| `tags` | стили через запятую | Жанр, настроение и звучание. |
| `audio_url` | URL файла | Исходное или референс-аудио. |

Поля, которые не относятся к выбранной операции, добавлять не нужно.

## Ответ

Задача выполняется в фоне. Готовый ответ содержит ссылку на аудио и ID трека для следующих операций. Чтобы сохранить ID отдельно, заранее создайте переменную PuzzleBot и передайте её имя в `music_id_variable`.
