# suno: простая генерация

Простой режим создаёт песню по одному описанию. Стоимость — `💠30`.

```jsonc
{
  "bot": "{{BOT_USERNAME_TEXT}}", // обязательно.
  "token": "[Ваш API-токен]", // обязательно.
  "user": "{{USER_ID_TEXT}}", // обязательно.
  "model": "suno", // обязательно.
  "action": "generate", // создать песню.
  "mv": "chirp-v5-5", // версия Suno.
  "prompt": "{{suno_prompt}}", // идея песни.
  "custom": false, // простой режим.
  "instrumental": false, // true для трека без вокала.
  "music_id_variable": "suno_music_id", // куда записать ID результата.
  "send_answer": true // отправить результат пользователю.
}
```

Suno возвращает на один запрос несколько вариантов трека. Чтобы работать с ними дальше — продлить, сделать кавер или выгрузить WAV — передайте `music_id_variable`: ID первого варианта попадёт в указанную переменную, второй — в `suno_music_id_2`. Переменные нужно создать в PuzzleBot заранее.

Для своего текста и точного стиля используйте [кастомную генерацию](suno-custom.md).
