# Озвучивание текста

Синтез речи превращает текст в аудио. Исходный голосовой файл для этого не нужен.

## Как отправить запрос

1. В настройках плагина выберите и включите модель **синтеза речи**, затем нажмите «Применить».
2. В PuzzleBot добавьте действие «Отправить запрос»: URL-адрес `https://api.pxsto.re/main/puzzlebot-tracker`, метод `POST`, вид **«Сформированный»**.
3. Передайте `model: global` и `type: voice`: трекер возьмёт модель озвучки из настроек вашего бота. Если модель там не выбрана, сначала настройте её.
4. В `prompt` передайте сам текст, который нужно произнести.

## Пример запроса с комментариями

```jsonc
{
  "bot": "{{BOT_USERNAME_TEXT}}", // обязательно: username бота.
  "token": "[Ваш API-токен]", // обязательно: токен интеграции PuzzleBot.
  "user": "{{USER_ID_TEXT}}", // обязательно: ID пользователя.
  "model": "global", // обязательно: использовать выбранную в плагине модель.
  "type": "voice", // обязательно для global: выбрать раздел синтеза речи.
  "prompt": "Здравствуйте! Ваша заявка принята.", // обязательно: текст для озвучивания.
  "send_answer": true // необязательно: отправить готовое аудио в чат.
}
```

Здесь не нужно писать «озвучь этот текст»: эта инструкция тоже может попасть в аудио. В «Сформированном» запросе добавьте ключи отдельными параметрами; для сырого JSON удалите комментарии `//`.

## Параметры

| Параметр | Обязательный | Описание |
| --- | --- | --- |
| `bot`, `token`, `user` | Да | Данные бота, токен интеграции и ID пользователя. |
| `model` | Да | `global` использует модель, выбранную в настройках плагина. |
| `type` | Для `global` | `voice` — синтез речи. Это не расшифровка входящего голоса. |
| `prompt` | Да | Текст, который должен прозвучать в записи. |
| `send_answer` | Нет | `true` — отправить аудио; `false` — использовать сохранённый результат. |

Голос и дополнительные настройки зависят от выбранной модели. Настройте их в форме этой модели; не переносите `alloy`, язык или формат из статьи другой модели.

## Ответ

Запрос выполняется асинхронно: HTTP-ответ подтверждает приём запроса, а не содержит готовый результат модели.

При `send_answer=true` готовый результат отправляется в чат. При `send_answer=false` отправка в чат отключена; используйте `{{tracker_answer}}` после завершения задачи. Сохранение в эту переменную должно быть включено в настройках бота. Для медиа значение переменной зависит от настройки «ссылка / file_id».

Для обратной задачи — текста из записи — используйте [Расшифровку аудио](transcription-catalog.md).
