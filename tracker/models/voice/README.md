# Голос: какую задачу выбрать

Голосовые задачи делятся на два разных сценария.

| Нужно получить | Что передать | Инструкция |
| --- | --- | --- |
| Текст из записи | ID аудиофайла в `file` | [Расшифровка аудио](transcription-catalog.md) |
| Аудио из текста | Текст в `prompt` | [Озвучивание текста](speech-catalog.md) |

Трекер — это действие «Отправить запрос» в сценарии PuzzleBot. В нём нет отдельной кнопки записи голоса. Сначала сценарий должен получить аудио пользователя и сохранить ID файла, затем передать этот ID в запросе. Один `prompt` с просьбой «расшифруй голос» не передаёт запись.

Если нужен обычный диалог с голосовыми сообщениями, настройте [обработку голоса в плагине](https://docs.pxsto.re/getting-started/nastroiki-i-upravlenie/muzyka-i-golos): пользователь отправляет голосовое самому боту, а не в форму трекера.

## Как получить результат

Запрос выполняется асинхронно: HTTP-ответ подтверждает приём запроса, а не содержит готовый результат модели.

При `send_answer=true` готовый результат отправляется в чат. При `send_answer=false` отправка в чат отключена; используйте `{{tracker_answer}}` после завершения задачи. Сохранение в эту переменную должно быть включено в настройках бота. Для медиа значение переменной зависит от настройки «ссылка / file_id».

[Общий порядок настройки трекера](https://docs.pxsto.re/tracker).
