# gpt_audio: ключ расшифровки аудио

`gpt_audio` — сохранённый ключ стандартного распознавания речи. Сейчас за ним стоит **Voxtral Mini Transcribe**; базовая стоимость — **💠2**.

Он принимает аудиофайл и возвращает **текст**. Для запуска нужен `file` с ID записи. Это не модель синтеза речи и не отдельный голосовой чат.

[Рабочий пример, получение ID файла и другие модели распознавания](transcription-catalog.md).

Для получения аудио из текста откройте [Озвучивание текста](speech-catalog.md).
