# Обработка медиа

Для увеличения изображения используйте [Topaz Image Upscale](../photo/image-upscale.md) с ключом `image_upscale`.

Музыкальные операции находятся в разделе [Музыка](../music/README.md), работа с файлами — в разделе [Создание документов](../text/document-creation.md).

Отдельной действующей модели с ключом `upscale` в каталоге нет.
