# Midjourney Video

Midjourney анимирует исходное изображение. Для создания видео обязательно фото; текст задаёт движение. Начальный ролик длится 5 секунд, каждое продление добавляет 4 секунды. Формат кадра наследуется от изображения.

## Как отправить запрос

- Ссылка: `https://api.pxsto.re/main/puzzlebot-tracker`
- Метод: `POST`
- Вид запроса в PuzzleBot: `Сформированный`

```json
{
  "bot": "{{BOT_USERNAME_TEXT}}",
  "token": "[Ваш API-токен]",
  "user": "{{USER_ID_TEXT}}",
  "model": "midjourney_video",
  "prompt": "Плавное движение камеры",
  "images": "https://example.com/source.jpg",
  "params": {"action":"generate", "resolution":"sd", "manual":"low", "bs":1},
  "send_answer": true
}
```

## Параметры

| Параметр | Обязательный | Описание |
| --- | --- | --- |
| `bot`, `token`, `user` | Да | Бот, API-токен и ID пользователя. |
| `model` | Да | `midjourney_video`. |
| `images` | Да для создания | Одно исходное фото: доступная ссылка или поддерживаемый file_id. |
| `prompt` | Да | Описание сцены и движения. |
| `params.ending_url` | Нет | Доступная ссылка на конечный кадр. |
| `params.resolution` | Нет | `sd` или `hd`; по умолчанию `sd`. |
| `params.manual` | Нет | Интенсивность движения: `low` или `high`. |
| `params.bs` | Нет | Количество роликов: 1, 2 или 4. |
| `send_answer` | Нет | Отправить результат в чат; по умолчанию `true`. |

Для продления используйте `params.action: "extend"`, `params.job_id` завершённой задачи и `params.video_index` от 0 до 3. Загрузка произвольного видео вместо ID задачи этот режим не заменяет. В Студии продление доступно из результата предыдущей генерации.

Текущая ручная ставка — 28 AI/сек. Перед запуском проверьте итоговую стоимость и количество вариантов. [Правила модели](https://docs.midjourney.com/hc/en-us/articles/37460773864589-Video).

## Ответ

Запрос выполняется асинхронно. При `send_answer=true` готовый результат отправляется в чат. При `send_answer=false` отправка отключена; сохранение в `{{tracker_answer}}` включается отдельно в настройках бота. Успешный HTTP-ответ подтверждает приём задачи, а не готовность ролика.
