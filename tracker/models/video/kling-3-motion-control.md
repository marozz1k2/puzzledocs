# Kling 3.0 Motion Control

Вариант Kling 3.0 Motion Control для генерации видео с управлением движением.

Для переноса движения нужны **изображение персонажа и видео движения**. Одного текстового описания недостаточно. Переменные в примере создаются и заполняются в вашем сценарии.

## Как отправлять запрос

- Ссылка: `https://api.pxsto.re/main/puzzlebot-tracker`
- Метод: `POST`
- Вид запроса в PuzzleBot: `Сформированный`
- Формат тела: `application/json` или те же ключи в no-code параметрах.

Обязательная база для любого запроса: `bot`, `token`, `user`, `model`. Опишите движение камеры, объектов и ключевые действия в `prompt`.

## Пример запроса с комментариями

```jsonc
{
  "bot": "{{BOT_USERNAME_TEXT}}", // обязательно: username бота в PuzzleBot.
  "token": "[Ваш API-токен]", // обязательно: API-токен бота для доступа к трекеру.
  "user": "{{USER_ID_TEXT}}", // обязательно: ID пользователя или сессии.
  "model": "kling_3_motion_control", // обязательно: точный ключ модели.
  "prompt": "{{prompt}}", // описание сцены и движения.
  "images": "{{character_image_url}}", // обязательно: изображение персонажа.
  "params": { // обязательно: исходное движение.
    "video_url": "{{motion_video_url}}" // обязательно: прямая ссылка на видео движения.
  }
}
```

## Параметры

| Параметр | Тип | Обязательный | Описание |
| --- | --- | --- | --- |
| `bot` | string | Да | Username бота. В PuzzleBot обычно используется `{{BOT_USERNAME_TEXT}}`. |
| `token` | string | Да | API-токен бота для авторизации запроса. |
| `user` | string | Да | ID пользователя или сессии. В PuzzleBot обычно используется `{{USER_ID_TEXT}}`. |
| `model` | string | Да | Точный ключ вызываемой модели: `kling_3_motion_control`. |
| `prompt` | string | Да | Описание видео с акцентом на траекторию движения, камеру и действия. |
| `images` | string | Да | Изображение персонажа; для этого сценария передайте один исходник. |
| `params.video_url` | string | Да | Прямая доступная ссылка на видео с исходным движением. |
| `send_answer` | boolean | Нет | `true` отправляет результат пользователю. `false` отключает отправку в чат. Сохранение в `{{tracker_answer}}` включается отдельно в настройках бота. По умолчанию `true`. |

## Ответ

Запрос выполняется асинхронно: HTTP-ответ подтверждает приём запроса, а не содержит готовый результат модели.

При `send_answer=true` готовый результат отправляется в чат. При `send_answer=false` отправка в чат отключена; используйте `{{tracker_answer}}` после завершения задачи. Сохранение в эту переменную должно быть включено в настройках бота. Для медиа значение переменной зависит от настройки «ссылка / file_id».
